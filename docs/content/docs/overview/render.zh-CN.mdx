# Render 部署

点击下面链接即可部署到 Render：

[部署到 Render](https://render.com/deploy?repo=https://github.com/tkxs/Zero-canvas)

## 部署步骤

1. 点击 `Deploy to Render`。
2. 登录 Render，并按页面提示连接 GitHub。
3. 选择后续保持不变的稳定生产域名。
4. 由外部官方服务登记精确的 `https://<域名>/oauth/callback` 回调地址和 `https://<域名>` CORS 来源。
5. 确认部署。

`USA0_ORIGIN` 默认是 `https://usa0.top`，仅在使用其他官方服务部署时覆盖。除本地回环地址可使用 HTTP 外，其余地址必须使用 HTTPS。OAuth 不支持通配符、随机预览域名或持续变化的部署地址，因此未经登记的 Render 分配域名本身不能完成登录。

所有业务页面都需要 USA零 OAuth。登录后会把官网全部 Key 自动同步为独立模型来源，同名模型仍可按 Key 区分，完整 Key 只保留在运行期内存。没有 Key 的用户需要在“账号管理”中选择官网分组并创建；创建和删除会直接更新作为数据源的官网。

## 免费版说明

默认使用 Render 免费 Web Service：

- 空闲约 15 分钟后会休眠，下次访问会自动唤醒。
- 画布、素材和生成记录默认保存在浏览器本地；第三方提示词由浏览器前端直连拉取。
- 免费服务休眠会影响首次打开速度，但不会替代 OAuth 的稳定域名和外部登记要求。

跨设备使用可自行配置 WebDAV 同步浏览器本地数据。
