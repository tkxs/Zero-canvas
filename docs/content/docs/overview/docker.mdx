# Docker Deployment

## Use the published image

```bash
git clone git@github.com:tkxs/Zero-canvas.git
cd Zero-canvas
docker compose up -d
```

Open `http://localhost:3000`.

## Build locally

```bash
docker compose -f docker-compose.local.yml up -d --build
```

## USA0 OAuth

`USA0_ORIGIN` selects the external official service and defaults to `https://usa0.top`. Set it as a container environment variable only when using another official service deployment. HTTPS is required except for loopback HTTP origins.

A production canvas deployment needs a stable origin. Before it can sign in, the external official service must register both the exact `<origin>/oauth/callback` redirect URI and the exact CORS origin. Wildcards, random preview domains, and changing deployment URLs are not supported.

```yaml
services:
  app:
    environment:
      USA0_ORIGIN: https://usa0.top
```

All business pages require OAuth. All official Keys and models synchronize automatically, each Key remains an independent source even for duplicate model names, and full Key values are kept only in runtime memory.

## Documentation image

The documentation in `docs/` is a separate Next.js standalone application with server capabilities.

```bash
cd docs
docker compose up -d
```

To build it from the current source:

```bash
cd docs
docker compose -f docker-compose.local.yml up -d --build
```

The main application container serves the built Vite SPA. Canvases, My Assets, and generation history are stored in the browser by default, while prompt repositories are fetched directly by the frontend. Full official Keys are runtime-only, so no persistent data volume is required for this data.

## Optional analytics

No analytics are enabled by default. A deployment can enable GA4, Baidu Analytics, or both at runtime:

| Variable | Description |
| --- | --- |
| `ANALYTICS_GA4_ID` | Google Analytics 4 measurement ID (`G-XXXX`) |
| `ANALYTICS_BAIDU_ID` | Baidu site ID, the hash after `hm.js?` |

```yaml
services:
  app:
    image: ghcr.io/tkxs/zero-canvas:latest
    ports:
      - "3000:3000"
    environment:
      ANALYTICS_GA4_ID: G-XXXXXXXXXX
      ANALYTICS_BAIDU_ID: e8263761cc5c32f5f7a855b8203b965a
```

SPA route changes automatically report page views to enabled providers. Only configure analytics IDs on sites you control, and do not commit them to the repository.
