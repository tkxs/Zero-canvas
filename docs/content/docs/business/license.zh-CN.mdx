# MIT 开源协议

USA零采用 [MIT License](https://github.com/tkxs/Zero-canvas/blob/main/LICENSE)。任何个人、团队和企业都可以免费、自由地使用本项目，没有使用场景和商业用途限制。

## 项目初衷

USA零保持开源，希望让更多人可以查看和修改代码，用画布组织提示词、参考图、素材和生成结果，并可基于源码制作符合自身需求的独立分支。标准版运行时统一使用 USA0 官网 Key 来源，不提供自定义渠道或 Provider 配置。


## 你可以做什么

- 免费使用、复制和修改代码。
- 发布原版或修改后的版本。
- 将项目用于商业产品、内部系统、私有化交付或在线服务。
- 将项目代码合并到开源或闭源软件中。
- 对项目或修改后的版本再授权或销售。

你不需要购买商业授权，也不需要公开自己的修改或业务代码。
